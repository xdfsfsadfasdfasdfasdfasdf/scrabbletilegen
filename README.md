# scrabbletilegen
Thank you for downloading scrabbletilegen,
a CLI app to calculate scrabble tile generation.

Important:
1. You must have the latest version of python downloaded.
2. You must have a dictionary file as txt.
3. NEVER insert the quotes in the » Path? Path.


How to use:
1. Open your terminal and run:
   ```python3 "\location of file\"```
2. Paste the path of the .txt file.
   ```» Path? C:\Users\user\lexicon.txt```
3. Insert info needed. Then, it will output results.
